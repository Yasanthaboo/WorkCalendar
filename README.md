## Workday Calculation

This application supports workday calculation based on configurable working hours and holidays.

### Features

- **Working Hours Configuration** — Define daily working hours (e.g., 9:00 AM – 5:00 PM). The total work duration per day is automatically derived from the configured start and end times.
- **Holiday Management** — Holidays can be configured as:
  - **Single-occurrence** — A one-time holiday on a specific date.
  - **Recurring** — Holidays that repeat on a regular schedule (e.g., annually).
